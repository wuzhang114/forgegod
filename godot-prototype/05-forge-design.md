# 锻造系统设计 v1(Tetra 式面板决策版)

> 状态:方向定稿(2026-09-01)
> 前置决定:锻造不做操作小游戏;采用 2D 像素面板交互(参考 Minecraft 匠魂 Tetra 的武器改造面板——MC Mod 原型已验证该模式可用)。
> 核心转变:可玩性来源 = **决策取舍 + 论据塑造 + 试错研究**,而非操作精确度。

## 1. 设计原则

1. **决策 > 操作**:每个面板页的一次选择都对应一个明确的取舍(数值/代价/论据三选二)。
2. **每个选择都生成事实**:面板上任何参数都会实时显示"将进入武器档案的事实卡片"——玩家锻造时就能看到"神会怎么评说这把武器"。
3. **工艺是论证而非分数**:4 维完成度不是排名,是为神前交涉提供证据;缺陷是合法构筑(裂纹=危险契约论据)。
4. **重要武器全手动,普通订单一键代工**:手作感只保留给值得记忆的作品。

## 2. 界面结构(像素风多页签面板)

```text
┌────────────────────────────────────────────────────────┐
│ [熔炼] [锻打] [热处理] [装配]        (页签切换)          │
├────────────────────────────────────────────────────────┤
│  中央:工件实时预览                    │ 右栏:当前选择    │
│  · 材料/温区热图                     │  · 参数(滑杆/选项)│
│  · 轮廓随尺寸变化                    │  · 特性标签(材料) │
│  · 应力/温度曲线                     │  · 代价预览        │
│                                      │                  │
│  底栏:即将写入档案的事实卡片实时刷新  │                  │
│   "材料:赤铜媒介芯 → 导流;热处理:温和 → 韧性稳定"      │
└────────────────────────────────────────────────────────┘
完成 → 生成 WeaponFacts(事实白名单 + fingerprint)
```

## 3. 四页签的决策点(每页 1-3 个选择,不做操作考核)

### 3.1 熔炼面板 —— 材料与配比

- 四部件(作用/承力/操控/媒介)× 材料下拉(每种材料 6 属性卡 + 特性标签)
- 合金(已解锁配方时):比例滑杆,关键阈值处解锁特性;未研究比例显示"?"(试错研究乐趣)
- **决策**:硬度 vs 韧性 vs 导能 vs 重量——部件职责不同,同一材料在不同部件价值天差地别
- 事实:材料特性标签直接进档案(如 `W2.material.red_copper`)

### 3.2 锻打面板 —— 尺寸与工艺倾向(不做点按游戏)

- 滑杆:长度 / 厚度 / 配重(实时影响:攻击距离/操控/重心/伤害,显示红绿箭头)
- 技法选择(随成长解锁):折叠、夹钢、分段、符槽…(每技法 1 个收益 + 1 个代价)
- **决策**:出速度奔袭还是要破甲爆发?重心前置=重击强但连续攻击差
- **"有意为之"分支**:一个单独按钮"保留应力"(结构度 -8,换 `defect.stress_crack` 缺陷标签)——**故意裂纹入口**,为危险契约(裂解爆发)铺路
- 事实:尺寸值 + 技法 + 缺陷标签

### 3.3 热处理面板 —— 淬火介质(仅选择,无时机考核;用户定)

- 介质 5 种:清水 / 油脂 / 盐泉 / 魔兽油 / 月泉(每种:硬度/韧性调整 + 元素标签)
- 回火:可选(取消激进效果,换稳定性)
- **决策**:硬而脆(破甲强) vs 韧而稳(容错高) vs 神秘介质(月泉=夜间/月光论据!)
- 事实:热处理值 + 介质标签(月泉淬火 → 神:"你用了月泉……")

### 3.4 装配面板 —— 结构与配重微调

- 部件方向/紧固方式/配重调整(滑杆),重心实时图
- **决策**:标准装配(平衡度高) vs 故意偏置(换取动作标签/论据)
- 事实:平衡度 + 装配方式标签

## 4. 手法风格(行为画像,替代操作技能)

面板选择被记录为行为画像,武器获得风格标签并影响神的第一句台词:

| 风格 | 判定 | 武器标签 | 神的态度 |
|---|---|---|---|
| 稳健 | 介质选择 ≥70% 温和向 | 「铁骨」 | "老成持重,知道你在这行吃过亏" |
| 险峻 | 介质选择 ≥70% 激进向(魔兽油/盐泉) | 「走钢」 | "又是你……这把刀也会跟你一样倔?" |
| 留一手 | 使用过"保留应力"≥2 次 | 「裂痕」 | "裂纹是实话,比完美更可信" |

风格标签 = 武器档案事实 + 战报标签 + 判例论据(三重用处)。

## 5. 与 WeaponFacts 的数据流

```text
面板选择(内存状态) → forge_core.build_facts(部件/材料/尺寸/工艺/缺陷)
  → {facts:[{id,text}], craft:{purity,structure,temper,balance},
      defects:[{id,label,desc}], fingerprint:sha256(canonical)}
  → 神前交涉(事实引用)→ 契约 → 战斗验证 → 战报回写
```

实现顺序:
1. `core/forge/forge_core.gd`:材料表/部件→四维/缺陷/事实生成/fingerprint(纯逻辑,headless 可测)
2. `scenes/forge/forge_scene.gd + tscn`:四页签面板 + 中央预览 + 事实卡底栏(Tetra 式)
3. 打通:forge_scene 完成 → WeaponFacts → 神前交涉面板(下一步假神 UI)
