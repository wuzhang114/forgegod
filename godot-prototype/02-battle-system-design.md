# 战斗系统设计 v1

> 状态：定稿基线（三轮问答 15 项决策 + 乘区体系研究 + 创作者补充规则）
> 更新时间：2026-09-01
> 前置：MechLang v0.3（契约特性/战斗查询/判定上下文已就绪）；战斗形式 = 自走棋式自动战斗 + 战术按钮；确定性离线模拟 + 回放播放器。
> 数值参考：Dota2/LoL 护甲公式（% 线性减伤）、PoE more/increased（乘法独立区鼻祖）、暗黑4 Damage Buckets（独立乘区翻车教训：膨胀→砍桶+上限）、原神《伤害乘区论》（固定 6-7 区、独立倍率稀缺）。

## 1. 设计目标与原则

1. **战斗是作品验证**：优先级 = 看懂 ＞ 爽 ＞ 平衡。
2. **可解释性优先**：任何伤害/状态变化都能回答"为什么"；连续随机浮动 = 不允许，用离散档位。
3. **确定性优先**：同 seed + 同输入流 → 相同事件流；模拟与呈现分离（离线模拟 + 播放器）。
4. **锻造是力量来源**：数值体系必须让"武器/契约"始终压过"装备/叠数"。

## 3. 伤害乘区体系 v1（核心）

### 3.1 六区公式（2026-09-01 定稿）

```text
最终伤害 = 基础攻击区 × 动作倍率区 × 增伤区 × 暴击区 × 防御区 × 独立乘区

基础攻击区:  武器面板 + 勇者基础 + 【装备的全部增伤】(线性加法)
动作倍率区:  动作标签自带倍率(重击×1.5 / 连击×0.6×N / 破甲×0.7 / 蓄力×2.0 / 远射×1.0)
增伤区:      通用/元素类增伤,同类加法 —— 上限 +100%
暴击区:      命中判定 roll → 三档: 暴击×1.5 / 普通×1.0 / 刮痧×0.7 (离散,非连续浮动)
防御区:      100 / (100 + 护甲值 - 破甲值)   [护甲下限 0]
独立乘区:    1 + (武器神赐增伤 + 目标易伤来源A + 来源B + ...)  —— 单一桶,内部加算,不连乘
```

### 3.2 来源规则（防膨胀铁律）

| 区 | 谁可以注入 | 数量/上限 | 设计意图 |
| --- | --- | --- | --- |
| 基础攻击区 | 武器面板、勇者基础、**装备全部增伤** | 无上限 | 装备是可堆叠资源,但只增线,不进乘 |
| 增伤区 | 通用/元素增伤(装备之外的被动、临时 buff) | **+100% 上限** | 堆词条有价值但明显递减 |
| 独立乘区 | **武器神赐增伤词条(每武器最多 1 个)** + 目标易伤状态(标记/燃烧/弱点…的易伤值) | 独立区来源**同桶加算** | 锻造/机制是唯一进入乘法的路径;组合目标是"凑齐来源"不是"叠数字" |

**三条铁律：**
1. 装备增伤永远进基础攻击区 —— 装备无法形成乘法成长,杜绝"一身装备碾压锻造"。
2. 独立乘区 = 单一桶:武器神赐(+X%) 与 目标易伤(+Y%) **加算** `1 + X + Y + ...`,任何来源之间不连乘 —— 直接吸收了 D4 独立乘区翻车教训。
3. 独立区来源数量受两类约束:每武器契约最多 1 个独立增伤词条(数值范围 1.05~1.5);目标易伤状态有存活时长与同状态刷新规则(见 §4)。

### 3.3 数值示例

| 情形 | 独立乘区 | 说明 |
| --- | --- | --- |
| 仅武器神赐 +20% | ×1.20 | 基础路径 |
| 武器 +20% + 标记易伤 15% | 1+0.20+0.15 = ×1.35 | 需要队友配合才能凑满 |
| 再加燃烧 10% | 1+0.45 = ×1.45 | 加算封顶收益(若连乘会是 1.52) |
| 假设 D4 式各来源连乘 + 装备进乘区 | ×2.0+ | 数值灾难,已禁止 |

### 3.4 与 MechLang 的映射（v0.3 已就绪 + v0.4 待补）

- v0.3 已就绪：`armor_value / target_evade / attack_value / hit_chance` 查询；`hit_landed / hit_crit` 上下文；契约 `traits { ignores_evade / guaranteed_hit / crit_mult }`。
- **v0.4 待补两条查询**：
  - `weapon_bonus("damage")` → 增伤区当前总额(0-1,按 +100% 封顶结算)
  - `vulnerability(target)` → 目标易伤桶当前值(0-2,含全部来源的加算和;由 sim 维护)
- 契约伤害公式约定示例：
  ```text
  dmg = attack_value() * 100 / (100 + armor_value(target)) * hit_crit
        * (1 + weapon_bonus("damage")) * (1 + vulnerability(target))
  ```
  独立乘区部分的 `vulnerability(target)` 已含武器词条(词条挂到"本武器对该目标的独立增伤"作为易伤来源之一登记)。

> `marked`(标记)本身是 MechLang 硬机制(set_mark/mark_count),不是状态;它的易伤贡献登记在目标易伤桶内(§3.2)。

### 4.6 通用规则

- 同状态不叠加,只刷新时长;DoT 层数 3 封顶(层数影响跳伤)。
- 硬控类共享控制递减(4 秒窗口:1× → 0.5× → 0.25×),软控/行为类不参与递减。
- 每个状态都有 ≥1 个清除通道;敌人与玩家共用(设计承诺:任何机制都有反制入口)。
- 状态 ID = 契约/战报/幻境唯一引用;新增状态必须同时登记本表 + 清除通道。

## 5. 判定链（攻击结算流程）

```text
攻击发动（前摇结束,判定窗）
  → 命中判定: roll < attack_hit - target_evade (traits.ignores_evade 跳过/guaranteed_hit 全跳过)
  → 格挡判定: 目标正在格挡 → 转格挡事件(伤害入块,blocked_damage 记入契约)
  → 伤害计算: §3.1 六区公式(离散三档浮动 roll 在此处,traits.crit_mult 参与)
  → 状态施加前提: 本击命中(若 miss,契约的 on hit 不触发,on attack 可读到 hit_landed=0)
  → 事件对象写入: {tick, source_id, action_tag, target_id, hit_landed, crit_tier,
                   base, armor_after, final_damage, statuses, cause_contract_ids[]}
  → 事件广播: sim -> MechLang VM(契约订阅)+ 播放器 + 战报聚合器
```

**事件对象是唯一协议**:契约、战报、幻境、播放器全部消费同一事件流。任何"为什么"= 查事件对象的对应字段。

## 6. 动作与定位模型

### 6.1 动作标签（武器定义,契约选择触发条件）

| 动作标签 | 倍率 | 特性 | 默认对应武器 |
| --- | --- | --- | --- |
| heavy_blow 重击 | ×1.5 | 长前摇,破甲 +20 | 战锤 |
| combo 连击 | ×0.6×N | 短前摇,连击增伤 | 长剑 |
| block 格挡 | ×0.0 | 挡下次伤害入"格挡块" | 盾/战锤 |
| parry 招架 | ×0.0 | 判定窗短,成功=反击+格挡 | 长剑 |
| charge 蓄力 | ×2.0 | 需完成蓄力帧 | 大剑/弩 |
| ranged 远射 | ×1.0 | 弹道标签 | 弓 |
| channel 引导 | ×1.2/s | 持续站桩 | 法杖 |

### 6.2 勇者定位（属性固定,装备/武器驱动发挥）

- **守卫**:默认目标=前排最近敌;指令"保护"优先;存在队友受击时优先格挡(职务优先,集火次之)。
- **连击手**:追击标记目标;低生命目标优先(处决倾向)。
- **射手**:最远站位;集火指令第一优先级(唯一全听指令的职业)。

### 6.3 指令（战术按钮,每场 3-5 次有效使用）

| 指令 | 效果 | 定义 |
| --- | --- | --- |
| 集火 | 指定目标 → **全员增加目标权重**(倾向,非锁定) | 射手完全响应;近战仅在无更急职务时响应;守卫仍履行保护/格挡职责 |
| 保护 | 指定一名队友,守卫贴身格挡 | 保护期间守卫输出大幅下降 |
| 过载 | 触发选中武器的**契约第二形态**(`on overload` 事件) | 契约生成时自带第二形态:更强效果 + 更大代价(例:回雷过载 = 24 伤 + 6 耐久);每场战斗次数有限 |
| 撤退 | 终止战斗,保留人员与装备 | 丢失本次出征剩余节点收益 |

> 过载语义(MechLang v0.4):`overload` 事件已加入 EVENTS 白名单;契约用 `on overload { ... }` 定义第二形态,触发时不消耗事件触发条件(比如"3 格挡后释放"的第二形态在过载时可直接释放但代价 ×2)。无第二形态的契约不可被过载(按钮置灰)。

### 6.4 敌人(模板级)

- 近战模板:靠近最近目标 → 攻击(前摇 0.6s) → 优先打守卫(仇恨规则)。
- 远程模板:站定射(弹道) → 被贴身时后撤一步(射程内)。
- M1 后期反制模板(净化者):周期性对玩家施加的易伤来源做净化(驱散标记/燃烧)。

## 7. 节点路线图（探索段）

```text
[出征] ─→ 节点1 ─→ 节点2 ─→ 节点3 ─→ [返回铁匠铺]
          战斗5-7敌   事件/补给    战斗5-7敌
```

- 节点类型:战斗(40%) / 补给休整(25%) / 敌军情报(20%) / 材料收获(15%)。
- **敌军情报节点**:揭示下一场战斗敌群构成(护甲/元素/反制),玩家据此预订配装——"实验"主题的决策点。
- 每次出征 2-3 场战斗 + 1-2 个事件;节点间允许一次"回撤"判定(损失未获收益)。
- 战斗间资源延续:耐久/热量/契约次数/状态持续保留,补给节点可修复/恢复(有限次数)。

## 8. 战斗播放器（自走棋式）

- 模拟离线完成(确定性,毫秒级)→ 播放器按**行动块**呈现(每名单位一次行动 = 一个块,自动衔接)。
- **行动块归属规则(自走棋式)**:凡是有独立实体的(勇者/敌人/召唤物如小精灵、樱树、影仆)各自拥有行动块,但**同阵营排布集中在一起**(随从块紧跟其召唤者),节奏不碎;纯状态/被动机制(无实体)不占块,并入所属者。
- 速度:0.5× / 1× / 2× / 单步 / 跳到结果;随时暂停与回看(行动块级时间线)。
- 干预按钮随时可用,指令进队列(带 tick 时间戳,不影响确定性)。
- 观看模式(底层同一事件流):行动块(默认) / 实时流(可选"大片模式")。

## 9. 战报字段 v1（按武器聚合）

- 触发/有效/浪费(无目标、目标已死、范围外)
- **未命中导致触发失败**(miss 分类,独立于"有效/浪费")
- 被格挡/被吸收/被免疫(反制入口命中统计)
- 独立乘区来源展示:武器词条 + 各易伤状态贡献(如"独立加成 +45%:神赐 20% + 标记 15% + 燃烧 10%")
- 代价支出(耐久/供物/自伤/热量)、缺陷触发、BREACH 熔断
- 联动(与队友武器/状态的组合)
- 每项都可点击追溯事件对象(因果链)
