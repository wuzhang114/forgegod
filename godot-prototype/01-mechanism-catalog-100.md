> 更新时间：2026-09-01
> 用途：MechLang 表达力考卷第三季。全部机制来自魔兽世界 / 宝可梦 / 塞尔达 / 空洞骑士 / 吸血鬼幸存者 / 以撒 / 杀戮尖塔 / 炉石 / 泰拉瑞亚 / 怪物猎人 / 艾尔登法环 / 黑神话 / 星穹铁道 / 明日方舟 / 王者荣耀 / 植物大战僵尸 / 元气骑士 / 挺进地牢 / Brawl Stars / 哈迪斯 / 死亡细胞 / 魔兽争霸 等 22+ 游戏，以及一批独立小游戏机制。

> 等级：**A** = 现有积木直接可搭（写出 MechLang 源码并入测试）；**B** = 缺 1–2 个动词（记录缺什么，列为 v0.3 候选）；**C** = 需要小队/世界/位置系统（未来层）。
