# 锻造系统升级方案 · 部件化与镶嵌

> 目标:把现有"四段选材"(作用/承力/操控/介质四件套)升级为 **Tetra 式部件化锻造**:
> ① 每种武器有自己的部件名称与部件职责;② 同一种材料在不同部件上的收益不同
> (材料 × 部件矩阵);③ 部分部件提供**镶嵌槽**,可镶宝石/符片获得额外属性与词缀。
> 本文只讲方案与取舍,不改代码;实施按文末步骤走。

---

## 一、验收标准(做完长这样)

1. 锻战锤时界面显示「锤头 / 锤柄 / 配重环 / 缚力符环」,锻长剑显示「剑身 / 剑脊 /
   护手 / 柄首宝石座」,锻弓显示「弓臂 / 弓弦 / 握把 / 箭羽座」——**部件名随武器走**。
2. 陨铁做锤头是招牌,做护手则力有不逮;黑木做握把顺滑,做剑身软——**材料与部件
   有适配差异**,且有提示说明("这料子不合这个位子,但也不是不能用")。
3. 武器有 2~3 个镶嵌槽,可装「烈焰玛瑙 / 雷击石 / 血珀 / 虚空晶」等;镶嵌物
   给小幅面板修正或词缀;词缀进入事实卡与神裁论据。
4. 四维(锻锤硬度链)不膨胀:材料四维仍在 1~10,适配系数 0.85~1.25,
   单槽镶嵌修正 ≤ ±8,「面板总量」与同级别手工铸造基本持平——差异化来自
   **词缀与论据**,不是数值碾压。

## 二、参考游戏的做法比对

| 游戏 | 它们怎么做 | 本作学什么 / 不学什么 |
|---|---|---|
| **Tetra**(MC) | 每种工件有专属**模块槽**(剑刃/剑柄/护手…);槽内模块由材料构成;材料属性逐槽叠加成工件属性;槽上可加**升级/改善**(improvement),含宝石、加长、磨利 | 学:模块化槽位 + 材料按槽生效 + 槽上改善件。不学:槽位可增减的"几何打磨"自由度(本作保持四段流程确定性) |
| **匠魂**(MC) | 工具 = 头部/柄/系绳;**材料属性表 × 部件作用域**(刃材料管攻速攻击,柄材料管耐久与右手加成);属性加权合成 | 学:材料属性表按部件作用域切分。本作已有(四维),本次把它做实、按武器差异化 |
| **暗黑2** | 武器/甲的**插孔**镶宝石(直接给属性);特定符文组合触发"符文之语"(专属词缀) | 学:镶嵌物=小修正,组合=大词缀。本作做"两档":普通宝石(数值修正)+ 符片(词缀,同槽互斥) |
| **艾尔登法环/黑魂** | 战灰(Ashes):替换战技并小幅改面板;强化链(锻造石) | 学:"改机制 vs 改数值"分离——**词缀进 MechLang 论据,数值进面板**,同一次锻造内选择 |
| **魔兽附魔** | 单一属性修正 ×N | 不学:无意义堆叠。本作镶嵌槽有限额(2~3 槽),防"附魔海" |
| **星露谷物语/传统锻造** | 材料升级链:普→铜→钢→金→铱 | 不学:线性升级会压死材料多样性;本作靠词缀搭配而非等级 |

一句话取舍:**槽位结构学 Tetra,属性合成学匠魂,镶嵌两档(宝石/符片)学暗黑,
机制与数值分离学法环**,但全部服从本作已有的"四段确定性流程"与"MechLang 契约"。

## 三、设计总览(三层)

```
┌─ 第 1 层:部件层 ────────────────────────────┐
│ 每种武器 = 4 个"部件槽"(沿用 action/bearing/  │
│ control/medium 四段,但每武器有专属名称与权重) │
├───────────────────────────────────────────────┤
│ 第 2 层:材料 × 部件矩阵                        │
│ 材料四维 × 部件权重 × 适配系数 → 部件属性贡献   │
│ 四段加权平均 → 纯度/结构/热处理/平衡(craft)     │
├───────────────────────────────────────────────┤
│ 第 3 层:镶嵌槽                                 │
│ 部分部件带 1 槽;镶宝石(数值)或符片(词缀);      │
│ 词缀进 facts → 神裁论据                         │
└───────────────────────────────────────────────┘
```

## 四、部件层:每武器专属部件表

沿用四段流程(熔炼→锻打→热处理→装配),**装配段显示武器专属部件名**;
内部键仍为 `action/bearing/control/medium`(存档结构不变,只换名字与权重)。

| 武器 | 作用件(action) | 承力件(bearing) | 操控件(control) | 介质件(medium) |
|---|---|---|---|---|
| 战锤 | 锤头 | 锤柄 | 配重环 | 缚力符环 |
| 长剑 | 剑身 | 剑脊 | 护手 | 柄首宝石座 |
| 弓 | 弓臂 | 弓弦 | 握把 | 箭羽座 |

**部件权重**(四维加权系数,H/T/D/C = 硬度/韧性/密度/传导):

| 部件职责 | 硬度 H | 韧性 T | 密度 D | 传导 C | 四维合成权重(总贡献) |
|---|---|---|---|---|---|
| 作用件 head | 1.0 | 0.7 | 0.4 | 0.6 | 0.42 |
| 承力件 bearing | 0.5 | 1.0 | 0.6 | 0.3 | 0.28 |
| 操控件 control | 0.3 | 0.5 | 1.0 | 0.5 | 0.20 |
| 介质件 medium | 0.2 | 0.3 | 0.4 | 1.0 | 0.10 |

> 设计意图:作用件决定"硬不硬"(热处理/暴击轴),承力件决定"结实不结实"
> (结构/耐久轴),操控件决定"顺手不顺手"(平衡/攻速轴),介质件决定
> "吃不吃魔法"(传导/词缀轴)。不同武器可微调这组权重(如弓的作用件→弓臂,
> 韧性权重大;剑的作用件→剑身,硬度权重更大),数值初期只做一套,后续按武器调。

**代码形状**(示意,不改现状):

```gdscript
const KINDS := {
  "warhammer": {"name": "战锤", "actions": [...],
    "parts": [
      {"id": "head",    "name": "锤头",     "role": "action",  "w": {"h": 1.0, "t": 0.7, "d": 0.4, "c": 0.6}, "desc": "决定锤击的威势与淬火深度"},
      {"id": "haft",    "name": "锤柄",     "role": "bearing", "w": {"h": 0.5, "t": 1.0, "d": 0.6, "c": 0.3}, "desc": "整根武器最不能断的地方"},
      {"id": "counter", "name": "配重环",   "role": "control", "w": {"h": 0.3, "t": 0.5, "d": 1.0, "c": 0.5}, "desc": "压住重心,挥起来才不飘"},
      {"id": "binding", "name": "缚力符环", "role": "medium",  "w": {"h": 0.2, "t": 0.3, "d": 0.4, "c": 1.0}, "desc": "缠住神语的接口"},
    ]},
  ...
}
```

## 五、材料 × 部件矩阵(核心差异化)

### 5.1 适配系数

每种材料在 `MATERIALS` 条目里加 `fit` 表,键为部件职责,值 0.85~1.25:

| 材料 | 作用件(head) | 承力件(bearing) | 操控件(control) | 介质件(medium) |
|---|---|---|---|---|
| 熟铁 | 1.15 | 1.00 | 0.95 | 0.90 |
| 赤铜 | 0.85 | 0.95 | 1.00 | **1.25** |
| 黑木 | 0.70 | 0.95 | **1.20** | 1.00 |
| 魔兽骨 | 0.90 | **1.15** | 0.90 | 0.80 |
| 陨铁 | **1.25** | 1.00 | 0.85 | 0.90 |
| 银木 | 0.75 | 0.90 | **1.15** | **1.15** |
| 虚空矿 | 0.95 | 0.85 | 0.90 | **1.25** |
| 霜钢 | **1.15** | 1.05 | 0.95 | 0.95 |

> 解读示例:陨铁做锤头/剑身=招牌(硬度 ×1.25),做护手/握把则"又沉又
> 不跟手"(操控 0.85);黑木做握把顺滑(1.20),做剑身软(0.70)。
> 每格数值在 UI 上以「★☆☆ / ★★☆ / ★★★」三档直观展示,鼠标悬停见具体值。

### 5.2 合成公式(改动集中在 forge_core `_compute_craft`)

```
部件四维贡献 = 材料四维 × 部件权重(w) × 适配系数(fit)
总四维       = Σ 部件贡献 / Σ 部件权重            (四段加权平均,带 medium 缺位惩罚)
```

- **纯度**:保留现有"熔炼把握 roll + 材料工艺难度"逻辑,但难度按**作用件材料**为主
  (其余部件小量参与);
- **结构**:承力件材料的韧性主导(现公式仅 bearing 一件参与,升级为权重合成);
- **热处理**:作用件硬度主导 + 淬火介质加成(不变);
- **平衡**:操控件密度参与重心计算(现公式只看尺寸偏置,改为尺寸 + 操控件密度小修正)。

### 5.3 差异化示例(同为面板 60 分的两把锤)

| 锤 | 锤头 | 锤柄 | 配重环 | 结果倾向 |
|---|---|---|---|---|
| A | 霜钢 | 魔兽骨 | 黑木 | 热处理高、结构高、平衡好 → 暴击/破甲/耐久三优 |
| B | 陨铁 | 熟铁 | 陨铁 | 热处理极高、配重拖手 → 爆发强但攻速偏低 |

两把战锤面板接近,但**词缀组合不同**(A:寒凝+饥性+回振;B:天外+耐修+天外),
玩家在"数值同档、风格各异"里做选择——这就是材料矩阵的价值。

## 六、镶嵌层

### 6.1 槽位(每武器固定 2~3 槽)

| 武器 | 槽位置 | 槽数 |
|---|---|---|
| 战锤 | 锤头 ×1、配重环 ×1 | 2 |
| 长剑 | 剑身 ×1、柄首宝石座 ×1 | 2 |
| 弓 | 弓臂 ×1、握把 ×1(箭羽座 1 槽为词缀专属) | 2~3 |

### 6.2 镶嵌物两档(同槽互斥,可替换)

**宝石档(数值修正)**——给该部件四维小幅修正:

| 镶嵌物 | 修正 | 来源域 |
|---|---|---|
| 烈焰玛瑙 | 作用件硬度 +6 | 余烬山脉 |
| 寒霜晶 | 作用件韧性 +5/传导 +3 | 白棘冻原 |
| 雷击石 | 介质件传导 +8 | 灰烬荒原 |
| 血珀 | 承力件韧性 +6 | 瘟疫洼地 |
| 星辉砂 | 操控件平衡 +5 | 秽根密林 |
| 虚空晶 | 介质件传导 +7/结构 -3 | 断界裂隙 |

**符片档(词缀)**——镶嵌物带来 trait(进入 facts,进神裁论据):

| 镶嵌物 | 词缀 | 论据 |
|---|---|---|
| 兽灵齿 | 「噬血」 | 吸血/饥性类论证 |
| 月髓片 | 「月约」 | 月光/夜间论证 |
| 灰烬尘 | 「复燃」 | 燃烧/重生论证 |
| 断界符 | 「窃界」 | 虚空/牵引论证 |

### 6.3 安装规则

- 每槽安装消耗:1 晶石 + 1 煤(或金币 25)——与锻造消耗链一致;
- 可替换:取下的旧镶嵌物保留 **50%**(消耗掉一半,防无成本反复洗);
- 词缀上限:全武器词缀(材料 trait+淬火+镶嵌)≤ 8 条,超出时新符片无法安装
  (提示"神语承重已满");
- 镶嵌物 id 记入 `facts`(如 `craft.socket.ember_agate`),fingerprint 纳入
  canonical(存档可复现)。

### 6.4 边界(防膨胀)

- 材料四维 1~10、适配 0.85~1.25、镶嵌四维修正 ±8,全部只作用于
  **部件级加权**,不产生新面板维度;
- 面板"总量守恒条约":用材适配系数 × 镶嵌修正后,单件武器面板总值得分上下
  浮动 < 15%(对比同四维均值),超标的数值以词缀/论据补偿,不以面板补偿。

## 七、接缝与影响面(哪几处会动)

| 文件 | 改动 |
|---|---|
| `core/forge/forge_core.gd` | KINDS 加 `parts` 表;MATERIALS 加 `fit`;`_compute_craft` 改为部件加权合成;新增镶嵌物表 `SOCKETS` 与装配入参(作 5 个可选参数:inventory? 不,镶嵌物列表直接进 build 的 craft_choices.sockets) |
| `core/forge/weapon_stats.gd` | 不变(四维→面板公式不动,镶嵌只调四维) |
| `scenes/forge/forge_scene.gd` | 装配段显示部件名与材料适配星级;新增「Ⅴ 铭刻」子步骤做镶嵌选择(或并入装配段) |
| `domain/weapon/contract_explainer.gd` | 词缀文本已有;适配新增 `craft.socket.*` 显示 |
| `tests/test_forge.gd` + 新 `test_forge_parts.gd` | 部件矩阵/适配星级/镶嵌/指纹稳定/总量守恒断言 |

**兼容性**:`build()` 签名不变(parts 键仍 action/bearing/control/medium),旧存档
武器 facts 已序列化,不受影响;新 build 的 fingerprint 含 sockets,新旧武器不混。

## 九、一句话总结

**Tetra 的"模块化槽位"给骨,匠魂的"材料×部件"给肉,暗黑的"宝石/符片两档"
给皮,法环的"机制与数值分离"给魂** —— 落点仍是四段锻造与 MechLang 契约:
每一次选材,都是在"部件适配上做取舍、在词缀上做投资、在神裁上做论证"。
