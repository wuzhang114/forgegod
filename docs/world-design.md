# 余烬世界 · 世界观拓展规划

> 目标:把「铁匠铺 × 锻造之神 × 契约武器」的玩法骨架,补上可支撑数十小时流程的
> 西幻世界 —— 尤其是**敌人**与**材料**这两条决定"玩什么、打什么、造什么"的主线。
> 本文先规划,实施按文末路线图逐期落地。

---

## 一、一句话设定

世界曾经被锻造之神的火点燃;神明在最后一炉里把自己锻进了世界,从此只留下
**火种**与**铁砧里的回响**。玩家是余火铁匠 —— 天生听得懂铁砧里的神语
(在游戏里就是 MechLang 契约)。神裁不是"找神做决定",而是**替沉默的神把
未完成的意志锻完**:你出的材料、你的主张,都会被神按"神语语法"解析。

这个设定直接支撑现有玩法:
- 锻造四段(主材/轴材/饰材/介质)→ 神语的"语法零件"
- 神裁对话 → 世界里的"神学辩论"(你的材质词缀就是论据)
- 契约生效 → 神语在战场上"言出法随"(MechLang 契约即神令残响)

## 二、冒险舞台:五域

西幻世界的骨架是**域域相隔、每域一脉材料与一脉敌人**。玩家每局远征由
"余烬山脚"出发,向断界裂隙推进;每域 3~6 层,首领镇尾。

| 域 | 主题 | 气息/主色调 | 核心敌人谱系 | 核心材料 | 域首领 |
|---|---|---|---|---|---|
| 余烬山脉 | 火山与熔核(已实现) | 熔橙 / 焦黑 | 构造魔像 | 熟铁、赤铜、煤 | 熔核巨像(已有) |
| 瘟疫洼地 | 瘴气与不死 | 黢绿 / 灰紫 | 疫群 + 骸骨亡灵 | 疫毒晶、魔兽骨、腐木 | 腐沼巫祝 |
| 白棘冻原 | 极寒与兽群 | 霜白 / 雾蓝 | 凶兽 + 精怪 | 白棘木、霜钢、兽骨 | 冰喉龙王 |
| 灰烬荒原 | 荒漠与商道 | 烬金 / 昏黄 | 沙匪 + 亡灵商旅 | 烬砂金、陨铁、盐泉 | 沙蝎王 |
| 秽根密林 | 藤蔓与旧德鲁伊 | 血棕 / 深绿 | 精怪 + 野兽 | 血藤芯、银木、黑木 | 幻影树灵 |
| 断界裂隙 | 虚空与堕神残迹 | 紫黑 / 微星 | 深渊族群 | 深渊尘、虚空矿 | 裂隙神子(终极) |

> 对应现有 `map_templates.gd` 四张战场背景:熔炉庭院→余烬山脉,断垣关道→灰烬荒原,
> 蓝晶矿窟→白棘冻原,秋枫神台→秽根密林;瘟疫洼地、断界裂隙各补一张背景即可。

**域推进规则(远征接缝)**:现远征地图 6 层 = 余烬山脉。拓展后改为
"每域 4~6 层 + 域首领层,通关入下一域",Boss 层结算奖励随域放大;
中间域可选(灰烬荒原/白棘冻原为"岔路",玩家自由选一条)。

## 三、敌人体系(规划核心)

### 3.1 谱系 × 角色矩阵

战斗模拟支持的角色槽(role)决定敌人的"行为模板",谱系决定它的"皮肤+掉落"。
现有三槽(brute 巨力 / shooter 远程 / purger 重甲);规划新增两槽,数值行加在
`balance.gd ENEMIES`(改动极小,行为复用现有移动/攻击逻辑):

| 角色槽 | 定位 | 现有数值 | 新增建议数值 | 行为特征 |
|---|---|---|---|---|
| brute | 近战巨力 | 120HP / 4攻 / 3甲 | — | 正面磨血 |
| shooter | 远程压制 | 102HP / 6攻 / 2甲 | — | 4 格射程 |
| purger | 重甲净化 | 150HP / 3攻 / 4甲 | — | 前排抗线 |
| caster | 术士(新增) | — | 96HP / 7攻 / 1甲 / 射程3 | 攻速慢,攻击**附带状态**(灼烧/中毒/冻结,由 pack 定义施法属性) |
| swift | 迅捷(新增) | — | 84HP / 5攻 / 0甲 / 闪避0.12 | 移动间隔 8(缠斗、绕后) |

**设计师手记**:新材料全部落在 **50~60 分的四维区间**附近(与现有八材同轴),
避免数值膨胀;真正的"稀有度"通过**词缀(论据)价值**体现,而不是面板数值。

### 4.3 材料与库存的接缝(现状缺口)

当前问题是 **锻造界面选材(forge_core.MATERIALS)与库存(inventory 里的
iron_ore/coal)是两套键**。规划统一:

1. 库存键直接使用材料 id(`grey_iron` 等),`coal`/`charm_crystal` 保留为
   工艺消耗品(淬火/铭刻用);
2. 旧档迁移:`load_dict` 时把 `iron_ore` → `grey_iron`(一次性,容错);
3. 锻造四段各消耗 1 份材料(主材必选,其余三段可"简配"但减产);
4. 每域敌人掉落 = 该域材料的**主要获取途径**(见 §3.2),商人与事件是补充。

### 4.4 经济闭环

```
敌人(域谱系) ──击杀──▶ 战报 loot ──结算──▶ 库存材料
                                              │
     征途资源(金币/声望)◀──事件/宝箱/商队────┤
     造武器(四段选材+淬火)◀─────────────────┘ 消耗材料+煤+晶石
              │
              ▼ 材料词缀 = 神裁"论据" ──▶ 神裁对话
              │                              │
              ▼                              ▼
        武器面板(四维→攻/命/暴/速/耐久)    契约(MechLang 神令)
              └────────── 战斗验证 ◀──────────┘
```

## 五、神裁与材料词缀(叙事钩子)

神裁的"论据"目前是武器事实。规划后,材料词缀成为**可引用论据**:
- 交涉时,系统把装备材料的词缀注入神裁上下文(如"这把剑用了深渊尘,你说过
  你的神令不喜虚空"→ 神可能顺着话题出更凶的契约);
- 特殊材料(神髓)可让神给出"神证"级契约(预算上限 +50%);
- 词缀在契约里也可见:`has_defect`/`material("bloodvine")` 类查询入 MechLang,
  让"材料决定机制"上到契约层(需要 MechLang 增加 material 查询,实施期评估)。

## 七、实施路线

- **P1(纯数据,现有接缝即可)**
  1. `forge_core.gd` 新增 8 材料(四维+词缀+来源注);
  2. 新增 `domain/world/world_registry.gd`(域表:名称/谱系/材料脉/首领/Bossid/背景归属);
  3. `enemy_packs.gd` 补各域编队(pack 挂 `domain` 与 `drops`);
  4. 战报 loot:结算时按 pack.drops 概率掉落(`expedition_rules.resolve_battle` 增加);
  5. 库存键迁移(load_dict 容错)+ 锻造消耗材料;
  6. 单测覆盖(材料表约束:四维 1~10、词缀非空、域-材料-编队完整性)。

- **P2(远征按域)**
  1. 域滚动:通关余烬山脉 → 岔路二选一(灰烬荒原/白棘冻原)→ 瘟疫洼地/秽根密林 → 断界裂隙;
  2. 每域战场背景归属 + 新增两张背景;
  3. caster/swift 角色槽入 balance,行为由 pack 施法属性驱动(灼烧/中毒/冻结攻击附带);
  4. 域首领编队轮换。

- **P3(叙事与神裁深耦合)**
  1. 材料词缀入神裁上下文(negotiation context 注入);
  2. MechLang `material()` 查询(契约读取武器材料);
  3. 神髓"神证"契约(预算上限扩充);
  4. 每域专属事件组(替换/扩充现 4 事件,事件与域材料挂钩)。

## 八、命名守则(延续现有味道)

- 材料:**两字为主**(熟铁/赤铜/月泉/白棘木/疫毒晶),不搞"XX 之 XX";
- 敌人:谱系 + 职能(**焦岩傀儡 / 嚎瘴毒囊 / 雪隐射手**),首领用"王/巫祝/神子"级后缀;
- 域:两字 + 地质词(余烬山脉/瘟疫洼地/白棘冻原/灰烬荒原/秽根密林/断界裂隙);
- 绝不出现:血条面板词、英文专名、谐音梗。
